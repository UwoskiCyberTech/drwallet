TELEGRAM SETUP (Detailed)
================================================================================

Step 1: Open Telegram app
Step 2: Search for @BotFather
Step 3: Send message: /newbot
Step 4: Name your bot: ALM Charges Test
Step 5: Username: alm_charges_test_bot
Step 6: Copy the TOKEN you receive

Step 7: Create new Telegram group
Step 8: Name it: ALM Test Charges
Step 9: Add your bot to group
Step 10: Get Chat ID from:
        https://api.telegram.org/bot{YOUR_TOKEN}/getUpdates
        Look for "chat":{"id":-XXXXXXXXX}
Step 11: Copy that negative number

You now have:
- TOKEN (from BotFather)
- CHAT_ID (negative number)

These go in .env.local file

================================================================================
TROUBLESHOOTING
================================================================================

Issue: App won't start
→ Check: npm run build completed
→ Fix: npm install again, then npm run build

Issue: Can't connect wallet
→ Check: MetaMask installed
→ Check: Switched to Polygon network
→ Fix: Refresh page

Issue: No Telegram notification
→ Check: .env.local has correct TOKEN and CHAT_ID
→ Check: Bot is in Telegram group
→ Fix: Verify with manual test (see guide)

Issue: Transaction stuck
→ Check: Wait 2 minutes
→ Check: Try different network
→ Fix: Refresh page and retry

Issue: High gas fee
→ Fix: Switch to Polygon network
→ Fix: Use Fantom network
→ Fix: Use Arbitrum network
