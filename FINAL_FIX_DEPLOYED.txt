Previous Error:
❌ Unknown method(s) requested
❌ RPC error on BSC

Root Cause:
- Passing chain object to wagmi caused method resolution issues
- wagmi couldn't properly serialize the transaction

Solution:
- Simplified transaction config
- Let wagmi automatically use the current chain after switching
- Removed explicit chain object from config
- Increased chain switch wait to 2 seconds

Before:
```javascript
sendTx({
  to: "0x...",
  value: ...,
  chain: chainObject  // ❌ Caused issues
})
```

After:
```javascript
// Switch chain first
await switchChain({ chainId: 56 });
await wait(2000); // Give wallet time to switch

// Then send transaction WITHOUT chain object
sendTx({
  to: "0x...",
  value: ...
  // ✅ No chain object - wagmi uses current chain from wallet
})
```
