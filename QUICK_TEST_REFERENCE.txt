$body = @{
    chat_id = $CHAT_ID
    text = "Testing"
} | ConvertTo-Json

Invoke-WebRequest -Uri "https://api.telegram.org/bot$TOKEN/sendMessage" `
  -Method Post `
  -ContentType "application/json" `
  -Body $body

================================================================================
TROUBLESHOOTING QUICK FIXES
================================================================================

Problem: App won't start
Fix: npm run build (check for errors)

Problem: Can't connect wallet
Fix: Refresh page, ensure MetaMask on Polygon

Problem: No Telegram message
Fix: Check .env.local has correct TOKEN and CHAT_ID

Problem: Transaction stuck
Fix: Wait 2 minutes, try again, or switch network

Problem: High gas fees
Fix: Use Polygon (Polygon Mainnet, not Mumbai testnet)

================================================================================
IMPORTANT NOTES
================================================================================

⚠️ Use POLYGON mainnet (not Mumbai testnet)
   - Mumbai might not work
   - Polygon has cheap/free gas

⚠️ Make sure MetaMask is connected to POLYGON
   - Check network selector at top
   - Should show "Polygon"

⚠️ Your wallet needs balance for:
   - The 15% charge amount
   - Gas fee (very small on Polygon)

⚠️ Save .env.local credentials
   - DO NOT commit to git
   - Keep .env.local private

⚠️ Keep npm run dev terminal open
   - Don't close it during testing
   - App runs while terminal open
