================================================================================
COMMON MISTAKES TO AVOID
================================================================================

❌ Pushing to GitHub with wrong username
   → Fix: Use actual GitHub username in git remote command

❌ Forgetting to set Root Directory to "apps/web" in Vercel
   → Fix: Go to Settings → Build & Development, set Root Directory

❌ Clicking Deploy without adding environment variables
   → Fix: Add all 6 variables BEFORE deploying

❌ Using old Telegram bot token
   → Fix: Get fresh token from @BotFather

❌ Testing with wallet that has <$3 balance
   → Fix: Need minimum $3 on EVM chains

❌ Not waiting for first build to complete
   → Fix: First build takes 5-10 minutes, normal

❌ Trying to deploy before pushing to GitHub
   → Fix: GitHub push must happen first
