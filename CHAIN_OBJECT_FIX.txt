┌────────────────────────────────────────────────────────────────────────────┐
│ WHAT WAS THE ISSUE                                                        │
└────────────────────────────────────────────────────────────────────────────┘

Error from your test:
❌ BSC: An unknown RPC error occurred.
   chain: undefined (id: 56)    <-- PROBLEM!
   Details: Unknown method(s) requested

Root Cause:
- wagmi's sendTransaction needs the FULL chain object
- We were only passing chainId
- wagmi couldn't find chain configuration
- Result: "chain: undefined" → RPC error

┌────────────────────────────────────────────────────────────────────────────┐
│ WHAT WAS FIXED                                                            │
└────────────────────────────────────────────────────────────────────────────┘

Before:
```javascript
const hash = await sendTx({
  to: config.to,
  value: config.value,
  data: config.data,
  chainId: config.chainId  // ❌ Not enough!
});
```

After:
```javascript
// Find the chain object
const targetChain = chains.find(c => c.id === config.chainId);

const hash = await sendTx({
  to: config.to,
  value: config.value,
  data: config.data,
  chain: targetChain  // ✅ Full chain object with RPC, name, etc.
});
```

Also increased chain switch wait time:
- Before: 1000ms (1 second)
- After: 1500ms (1.5 seconds)
- Gives wallet more time to complete switch
