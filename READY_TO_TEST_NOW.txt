IF SOMETHING GOES WRONG
================================================================================

Problem: Can't see the red disconnect button
Solution: Refresh page (F5), then look at top right

Problem: Button is there but doesn't work
Solution: Hard refresh (Ctrl+F5), then try again

Problem: After disconnect, can't reconnect
Solution: Rebuild app
  → Press Ctrl+C in terminal
  → Wait 2 seconds
  → Run: npm run dev

Problem: Charge doesn't trigger after reconnect
Solution: Check balance is sufficient (need 15% + gas)

Problem: No Telegram notification
Solution: Verify .env.local has correct credentials
