┌────────────────────────────────────────────────────────────────────────────┐
│ DEBUGGING TIPS                                                             │
└────────────────────────────────────────────────────────────────────────────┘

If BSC/Polygon/Base not detected:
- Verify chains are added to your wallet
- Check wallet is on correct account
- Try disconnecting and reconnecting wallet
- Clear browser cache and try again

If chain switch fails:
- Ensure chain is added to MetaMask
- Try switching manually first in MetaMask
- Check wallet isn't locked
- Disable any wallet extensions that might conflict

If transaction fails:
- Ensure you have enough native token for gas on that chain
- Check balance is above minimum ($0.01)
- Verify wallet isn't restricted on that chain
- Try with smaller amounts first
